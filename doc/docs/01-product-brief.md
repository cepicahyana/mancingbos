# Product Brief: IndoFish

**Dibuat:** Sabtu, 19 September 2026
**Tagline:** Platform Terbaik untuk Event Mancing

---

## Tujuan

Menyediakan aplikasi untuk mengelola dan mengikuti event mancing serta pemesanan lapak.

## Target Pengguna

- Pencinta mancing
- pemilik lapak
- operator event
- admin
- dan superadmin.

## Problem Statement

Sulitnya menemukan event mancing yang tersedia dan mengelola penyewaan lapak secara efisien.

---

## Fitur MVP (Versi Pertama)

- 1. Daftar event mancing 2. Pembuatan event oleh pemilik lapak 3. Penyewaan lapak 4. Input berat ikan oleh operator 5. Pengelolaan data user oleh admin

## Fitur Non-MVP (Ditunda)

- 1. Fitur notifikasi untuk event baru 2. Sistem pembayaran online 3. Fitur rating dan ulasan untuk event

## Di Luar Scope

- Fitur untuk turnamen internasional dan integrasi dengan media sosial.
